================================================================
OLRAC ADVERSE - DEPLOYMENT GUIDE (AWS EC2 + GODADDY)
================================================================

OVERVIEW
--------
Host the entire stack on a single AWS EC2 instance using your
GoDaddy domain olracad.com. Nginx serves both frontends and
proxies API traffic to FastAPI running via Gunicorn.

  Domain Layout:
    olracad.com          → React client site
    admin.olracad.com    → React admin site
    api.olracad.com      → FastAPI backend

  Stack on EC2:
    Nginx                → reverse proxy + static file server
    Gunicorn + Uvicorn   → FastAPI backend (port 8000, internal)
    PostgreSQL           → database (local on EC2)
    Let's Encrypt        → free SSL certificates


================================================================
STEP 1 — GoDaddy DNS SETUP
================================================================

1. Log in to GoDaddy → My Products → Domains → click "DNS"
   next to olracad.com

2. Add 4 A records pointing to your EC2 Elastic IP address:

   Type  | Name    | Value        | TTL
   ------|---------|--------------|-----
   A     | @       | <EC2-IP>     | 600
   A     | www     | <EC2-IP>     | 600
   A     | admin   | <EC2-IP>     | 600
   A     | api     | <EC2-IP>     | 600

3. Save and wait 10–30 minutes for DNS to propagate.

NOTE: To find your EC2 Elastic IP → AWS Console → EC2 →
Elastic IPs. If you don't have one, allocate and associate
it to your instance first (prevents IP changing on restart).


================================================================
STEP 2 — EC2 SERVER SETUP
================================================================

SSH into your EC2 instance and install all dependencies:

   sudo apt update && sudo apt upgrade -y

   # Python
   sudo apt install -y python3 python3-pip python3-venv

   # Node.js 20 LTS
   curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
   sudo apt install -y nodejs

   # Nginx, Certbot, PostgreSQL
   sudo apt install -y nginx certbot python3-certbot-nginx \
     postgresql postgresql-contrib

   # Playwright system dependencies (for PDF invoice generation)
   sudo apt install -y libnss3 libatk1.0-0 libatk-bridge2.0-0 \
     libcups2 libdrm2 libxkbcommon0 libxcomposite1 libxdamage1 \
     libxfixes3 libxrandr2 libgbm1 libpango-1.0-0 libcairo2 libasound2

IMPORTANT: In AWS Console → EC2 → Security Groups → Inbound Rules,
make sure ports 22, 80, and 443 are open.


================================================================
STEP 3 — POSTGRESQL DATABASE SETUP
================================================================

   sudo -u postgres psql

   # Inside psql, run:
   CREATE DATABASE olrac;
   CREATE USER olracuser WITH PASSWORD 'YourStrongPassword';
   GRANT ALL PRIVILEGES ON DATABASE olrac TO olracuser;
   \q

Your DATABASE_URL will be:
   postgresql://olracuser:YourStrongPassword@localhost:5432/olrac


================================================================
STEP 4 — DEPLOY THE BACKEND
================================================================

--- 4a. Clone the project ---

   git clone https://github.com/roshannandhu/Olrac.git /home/ubuntu/olrac

--- 4b. Set up Python environment ---

   cd /home/ubuntu/olrac/backend
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   pip install gunicorn

   # Install Playwright browser (for PDF invoices)
   python -m playwright install chromium
   python -m playwright install-deps chromium

--- 4c. Create the backend .env file ---

   nano /home/ubuntu/olrac/backend/.env

Paste and fill in:

   DATABASE_URL=postgresql://olracuser:YourStrongPassword@localhost:5432/olrac

   JWT_SECRET_KEY=<run: openssl rand -hex 32>
   JWT_ALGORITHM=HS256
   JWT_EXPIRY_MINUTES=1440

   SMTP_HOST=smtp.gmail.com
   SMTP_PORT=587
   SMTP_USER=your@gmail.com
   SMTP_PASSWORD=your-gmail-app-password
   SMTP_FROM_NAME=Olrac

   GROQ_API_KEY=your-groq-api-key
   GROQ_MODEL=llama3-70b-8192

   WHATSAPP_ADMIN_NUMBER=919876543210

   DEFAULT_ADMIN_NAME=Admin
   DEFAULT_ADMIN_EMAIL=admin@olracad.com
   DEFAULT_ADMIN_PASSWORD=YourStrongAdminPassword
   DEFAULT_ADMIN_SYNC_PASSWORD=true

   CORS_ORIGINS=https://olracad.com,https://www.olracad.com,https://admin.olracad.com
   CORS_ORIGIN_REGEX=

--- 4d. Create the systemd service ---

   sudo nano /etc/systemd/system/olrac-backend.service

Paste:

   [Unit]
   Description=Olrac FastAPI Backend
   After=network.target postgresql.service

   [Service]
   User=ubuntu
   WorkingDirectory=/home/ubuntu/olrac/backend
   Environment="PATH=/home/ubuntu/olrac/backend/venv/bin"
   EnvironmentFile=/home/ubuntu/olrac/backend/.env
   ExecStart=/home/ubuntu/olrac/backend/venv/bin/gunicorn app.main:app \
     -w 2 -k uvicorn.workers.UvicornWorker \
     --bind 127.0.0.1:8000 \
     --timeout 120
   Restart=always

   [Install]
   WantedBy=multi-user.target

Enable and start:

   sudo systemctl daemon-reload
   sudo systemctl enable olrac-backend
   sudo systemctl start olrac-backend

Test it:

   curl http://127.0.0.1:8000/health
   # Should return: {"status":"healthy"}


================================================================
STEP 5 — BUILD THE FRONTENDS
================================================================

--- 5a. Build the client site (olracad.com) ---

   cd /home/ubuntu/olrac/frontend
   npm install --legacy-peer-deps

   VITE_SITE_MODE=client \
   VITE_API_BASE_URL=https://api.olracad.com \
   VITE_CLIENT_SITE_URL=https://olracad.com \
   VITE_ADMIN_SITE_URL=https://admin.olracad.com \
   npm run build:client

--- 5b. Build the admin site (admin.olracad.com) ---

   VITE_SITE_MODE=admin \
   VITE_API_BASE_URL=https://api.olracad.com \
   VITE_CLIENT_SITE_URL=https://olracad.com \
   VITE_ADMIN_SITE_URL=https://admin.olracad.com \
   npm run build:admin

--- 5c. Copy built files to web root ---

   sudo mkdir -p /var/www/olrac/client
   sudo mkdir -p /var/www/olrac/admin

   sudo cp -r dist/client/. /var/www/olrac/client/
   sudo cp -r dist/admin/. /var/www/olrac/admin/


================================================================
STEP 6 — NGINX CONFIGURATION
================================================================

--- 6a. Client site ---

   sudo nano /etc/nginx/sites-available/olrac-client

Paste:

   server {
       listen 80;
       server_name olracad.com www.olracad.com;
       root /var/www/olrac/client;
       index index.html;

       location / {
           try_files $uri $uri/ /index.html;
       }
   }

--- 6b. Admin site ---

   sudo nano /etc/nginx/sites-available/olrac-admin

Paste:

   server {
       listen 80;
       server_name admin.olracad.com;
       root /var/www/olrac/admin;
       index index.html;

       location / {
           try_files $uri $uri/ /index.html;
       }
   }

--- 6c. API ---

   sudo nano /etc/nginx/sites-available/olrac-api

Paste:

   server {
       listen 80;
       server_name api.olracad.com;

       client_max_body_size 100M;

       location / {
           proxy_pass http://127.0.0.1:8000;
           proxy_set_header Host $host;
           proxy_set_header X-Real-IP $remote_addr;
           proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
           proxy_set_header X-Forwarded-Proto $scheme;
           proxy_read_timeout 120s;
       }
   }

--- 6d. Enable and reload ---

   sudo ln -s /etc/nginx/sites-available/olrac-client /etc/nginx/sites-enabled/
   sudo ln -s /etc/nginx/sites-available/olrac-admin  /etc/nginx/sites-enabled/
   sudo ln -s /etc/nginx/sites-available/olrac-api    /etc/nginx/sites-enabled/

   sudo nginx -t
   sudo systemctl reload nginx


================================================================
STEP 7 — SSL CERTIFICATES (Let's Encrypt)
================================================================

   sudo certbot --nginx -d olracad.com -d www.olracad.com
   sudo certbot --nginx -d admin.olracad.com
   sudo certbot --nginx -d api.olracad.com

Certbot automatically edits the Nginx configs to redirect HTTP
to HTTPS and installs auto-renewal. Verify auto-renewal with:

   sudo systemctl status certbot.timer


================================================================
STEP 8 — CODE CHANGE NEEDED (do this before deploying)
================================================================

FIX — backend/app/main.py
Replace these 2 lines:
   os.makedirs("uploads", exist_ok=True)
   app.mount("/uploads", StaticFiles(directory="uploads"), name="uploads")

With:
   from pathlib import Path
   UPLOAD_DIR = Path(__file__).resolve().parent.parent / "uploads"
   UPLOAD_DIR.mkdir(exist_ok=True)
   app.mount("/uploads", StaticFiles(directory=str(UPLOAD_DIR)), name="uploads")

WHY: The relative path breaks when Gunicorn is run as a systemd
service because the working directory may differ from the repo root.
